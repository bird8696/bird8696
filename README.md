## 📌 Projects

### 🔐 피싱 이메일 탐지기
![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat&logo=fastapi&logoColor=white)
![Claude API](https://img.shields.io/badge/Claude_API-Anthropic-black?style=flat)

Claude AI를 활용해 이메일의 피싱 여부를 자동으로 분석하는 **FastAPI 기반 REST API 서버**.  
별도의 학습 데이터 없이 Claude에게 보안 전문가 역할을 부여, 이메일의 위험도와 대응 방법을 자연어로 제시합니다.

- Claude API 기반 피싱 탐지 로직 구현 (Zero-Shot Prompting)
- 위험도 3단계 분류 (LOW / MEDIUM / HIGH) 및 대응 방안 자동 생성
- FastAPI + Pydantic 기반 REST API 구조 설계
- Swagger UI를 통한 직관적인 테스트 환경 제공

```json
// 분석 결과 예시
{
  "is_phishing": true,
  "risk_level": "HIGH",
  "reason": "발신자 주소 위장 및 긴급성 유도, 개인정보 요구",
  "recommendation": "링크를 클릭하지 말고 즉시 삭제하세요."
}
```
